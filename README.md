# Python Basics Programs

This repository contains six basic Python programs created for learning and practice.

## Programs

### 1. factorial.py

Calculates the factorial of a number using a loop.

### 2. fibonacci.py

Generates a Fibonacci series using a loop.

### 3. dictionary.py

Demonstrates basic Python dictionary operations.

### 4. list.py

Demonstrates basic Python list operations.

### 5. multiplication.py

Prints the multiplication table of a number.

### 6. pattern.py

Prints a simple star pattern using nested loops.

## Requirements

Python 3 is required to run these programs.

No external Python libraries are required.

## How to Run

Open a terminal in the repository folder.

Run any program using:

```bash
python filename.py

python factorial.py
